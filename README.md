Reminder helps you keep important things in mind. Choose a message, date, and time, then let the app bring it back to your attention in a full-screen alert.

## Features

- Schedule one-time reminders for a specific date and time.
- Repeat reminders daily, on weekdays, weekly, or monthly.
- Choose a background color for the full-screen alert and preview it in the app.
- Keep reminders and appearance settings saved locally on your computer.
- Queue alerts when multiple reminders are due at the same time.
- Acknowledge an alert when you are ready to continue.

Reminder works locally and does not require an internet connection or a backend server. The app must be running and the computer must be on for an alert to appear. A reminder that became due while the app was closed will be handled when you open the app again.

## Requirements

- Windows 10 or later to run the desktop app.
- Node.js 20 or later and npm to develop or build the app.

## Run in development

Open a terminal in the project folder and run:

```bash
npm install
npm run start
```

This starts the Vite development server and opens the Electron app. Keep the terminal running while you use the app. Press `Ctrl+C` in the terminal to stop it.

## Build the app

Create production files with:

```bash
npm run build
```

Create a Windows installer with:

```bash
npm run dist:win
```

The installer is written to `release/`. The folder may also contain `win-unpacked/` and installer metadata generated by electron-builder.

The installer uses a guided setup and lets you choose an installation folder. On the install-mode screen, choose **Just for me** for a per-user install, or choose the all-users option if you want it available to every account on the computer. Installing for all users may require administrator permission.

## Project structure

```text
src/
  electron/     Main process, windows, IPC, and reminder scheduling
  renderer/     React screens, components, hooks, and styles
  shared/       Shared types and calendar scheduling rules
assets/         README artwork
dist/           Built renderer files
dist-electron/  Built Electron files
release/        Windows installer output
```

Build output folders are local and excluded from Git.
